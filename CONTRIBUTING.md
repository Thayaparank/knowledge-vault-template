# Contributing

This repo is a **template for a personal knowledge vault** — the method, not anyone's actual knowledge. Contributions that improve the method are welcome:

- Better wording or structure in the README or AGENTS.md rules
- New or improved note templates in `templates/`
- New "adapt to your field" examples (categories for professions not yet covered)
- Fixes to broken links, typos, inconsistencies

## Ground rules

1. **No real knowledge content.** The vault ships empty — no actual bug fixes, contracts, notes, or personal data. Example content must be clearly fictional.
2. **Keep it domain-neutral.** The base structure must work for any field; field-specific ideas belong in the "adapt to your field" table, not in the base folders.
3. **One concept per change.** Small, focused pull requests — the same rule the vault itself follows.
4. **AGENTS.md changes get extra scrutiny.** That file is executed as instructions by AI assistants (the CLAUDE.md / GEMINI.md / copilot-instructions.md pointers must stay one-line redirects to it). Rule changes must be safe, generic, and clearly beneficial.

Open an issue first for anything larger than a small fix.
